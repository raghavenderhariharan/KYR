Why it matters

Reports hold the answers. Files keep them locked away.

Every scheduled report your ERP prints is full of answers people need: discrepancies, negative availability, open orders. Know Your Reports turns each one into a definition with four guarantees, and every guarantee is built by a specific step in the wizard.

After you click save

From configuration to live data

“Save configuration” doesn't just store settings. It schedules a live pipeline based on the Run frequency chosen in Step 1.

1 · Trigger

Scheduled Trigger

The Run frequency set in Step 1 (e.g. Daily) fires the job automatically, no manual kickoff needed.

2 · Retrieve

RPA Pulls the Report

An RPA job connects to the source ERP and retrieves the latest report file for that run.

3 · Parse

Script Executes

The generated & validated parsing script runs against the fresh file, extracting every mapped field.

4 · Index

Pushed to Search Index

Structured results are pushed to the Search Index API. Instantly queryable, with no manual re-entry.

Set once, it repeats. The Run frequency configured in Step 1 drives this entire pipeline and repeats automatically from there.
